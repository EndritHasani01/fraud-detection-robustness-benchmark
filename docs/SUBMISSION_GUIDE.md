## What is included

The repository retains the report, slides, code, frozen configurations, executed notebook, unified results, graph-variant audits, plots, execution manifests, and regression tests. Dataset downloads, cached graphs, local development runs, and archived drafts are excluded from the Git handoff. Cached graphs are regenerated by execution.

Check the PDF and slides personally before sending, and verify the remote repository shows the new structure after committing and pushing. This organization task does not send an email or publish changes.
